# 按歌名自动翻唱

已接入 `astrbot_plugin_fish_singing` 1.0.2。用户试听鞠婧祎《叹云兮》的25秒换声结果后确认采用这个效果，再部署到云端。唱歌功能复用当前选定的净化参考声音，不替换原说话权重。

后续增加显卡分离、模型复用、成品缓存与超时提示，并修复了消息后置插件中断音频回传的问题，见[加速与修复说明](唱歌加速与回传修复.md)。用户已在真实QQ确认收到两段语音。

## QQ中使用

```text
/唱歌 叹云兮 鞠婧祎
/翻唱 歌名 歌手
```

歌名和歌手用空格分开；也支持 `唱歌 歌名 歌手`、`唱一首 歌名 歌手`。直接发送歌曲URL不被接受。默认所有未被主人禁止的用户可点歌，普通用户间隔300秒，主人免冷却；一次只处理一首。可在插件配置把 `owner_only` 改为true。

大肥鱼自动搜索原唱，先取平台提供的可用整曲，取不到时尝试平台的公开试听。找到试听时会明确说明，不把试听说成整首。找不到匹配歌手或没有可用音源时提示失败，不需要额外的音乐解析API Key，也不会绕过平台的登录或付费限制。

《叹云兮》本次只能获得60秒公开试听，因此真实验收输出为60秒翻唱，按约50秒和10秒两条语音回传；不是整首歌曲。其他歌曲是否可取得整曲取决于平台当时的返回。

## 如何工作

QQ指令→云端插件→已有私有语音连接→本机任务接口→QQ音乐公开搜索和播放/试听链接→MDX人声分离→Seed-VC歌声换音色→混回伴奏→50秒分段→云端音频文件→QQ语音。

使用 Seed-VC 44.1k 歌声模型，开启F0条件，30步扩散，不自动升降调。音色参考读取 `local-voice/trained-voice.json` 中的 `reference_audio`，因此采用同一份净化录音；GPT-SoVITS的说话权重不能直接当作歌声转换权重使用。

输入最长处理前300秒，文件上限25MB，结果最多6段，单段上限2MB。超过五分钟时会说明截取范围。任务编号幂等，一次只允许一个worker运行，异常或超时会明确失败；不会将不完整结果冒充完整歌曲。

## 本地部署

1. 在运行目录建立 `singing`，把本仓库该目录的代码与 `local-voice` 新代码放到对应位置。
2. 在 `singing/.venv` 创建独立Python 3.12环境，先安装适配显卡的Torch。原环境为RTX 5060 Laptop 8GB、`torch==2.7.1+cu128`、`torchaudio==2.7.1+cu128`，官方轮子源为 `https://download.pytorch.org/whl/cu128`。
3. 安装 `singing/requirements.txt` 的其余依赖；原Torch包来自上一步的官方CUDA源，不要用默认PyPI替换成不匹配的GPU版本。
4. 克隆 [Seed-VC](https://github.com/Plachtaa/seed-vc) 到 `singing/seed-vc`，本次固定提交 `51383efd921027683c89e5348211d93ff12ac2a8`；应用 `singing/seed-vc-optional-dac.patch`。
5. 该补丁将未启用的DAC量化器改为按需导入。选用的连续特征歌声模型不使用它，避免可选DAC依赖的旧protobuf要求与新ONNX分离工具冲突；不需要安装整套Gradio或DAC训练环境。
6. 联网运行 `singing/prepare_models.py` 下载歌声模型、RMVPE、CAMPPlus、BigVGAN、Whisper-small和 `UVR-MDX-NET-Inst_HQ_3.onnx`。首次模型下载需要数GB空间；权重不随仓库分发。
7. 保留当前 `trained-voice.json`；更新后的19880服务加载 `singing_jobs.py`，无需新增公网端口或SSH账号。停止并重新启动本地声音管理器以载入新代码。
8. 将 `custom-plugins/astrbot_plugin_fish_singing` 打包安装到云端AstrBot，填写自己的主人QQ。可以使用 `云端部署/install-singing.py`，其面板地址和私下创建的登录文件与原部署约定一致。
9. 先运行 `singing/verify_local.py`，此脚本真实生成测试歌曲、取回分段，但不向QQ发送。首次还应从云端通过Unix socket读取完成任务与音频，确认能解码，再在QQ中点歌。

唱歌和说话共享本机显卡互斥锁。换声期间若说话拿不到锁，原语音路由会自动使用龙嫱备用；歌曲完成后自动重新使用原本地声音。电脑断网或未运行本地服务时，唱歌提示不可用，普通云端聊天仍继续。
