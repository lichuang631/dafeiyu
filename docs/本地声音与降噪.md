# 大肥鱼本地声音

本地运行目录：`D:\dafeiyu\local-voice`。大肥鱼的 QQ、对话和空间功能继续在原服务器运行。

## 日常使用

双击安装根目录的 `启动本地声音.bat`。本地声音服务在后台运行，并自动建立、恢复服务器连接。电脑保持开机联网时，服务器优先使用本地训练的声音。

电脑关机、断网、模型报错或合成超时时，大肥鱼自动使用百炼原有的“龙嫱”声音。本地恢复后会自动尝试本地声音。语音60%、文字40%的设置保留。网络恢复时，只要本地管理器仍在运行就会自行重连，不需要重新点击启动或切换音色；机器人在下一次语音请求时恢复本地声音，刚失败后的重试间隔为15秒。

双击 `停止本地声音.bat` 停止本地语音服务及连接；服务器上的大肥鱼继续运行，使用原来的云端声音。电脑重启后需要重新双击启动入口。

## 训练素材与模型

用户提供的《标准录音 6.mp3》约155秒，原件复制到 `local-voice\data\raw\reference.mp3`，不会改动微信下载目录中的文件。

先用本地 Whisper 识别，再用机器人现有的百炼听写服务交叉核对。剔除不确定片段后保留16个短句、约83秒。转录和筛选记录保存在 `local-voice\data`。训练和后续本地语音生成使用本机 RTX 5060 Laptop 8GB 显卡。

采用 GPT-SoVITS v2ProPlus，独立环境中固定 PyTorch 2.7.1 + CUDA 12.8。中文多音字处理使用 CPU 版 ONNX Runtime，避免和声音模型争用显存。训练参数为批次2、音色阶段8轮、GPT阶段15轮。参数文件保存在 `local-voice\train-s2.json` 与 `train-s1.yaml`。

第二版使用第6、8份录音，用户发错的第7份不参与处理和训练。原文件均保留。使用 DeepFilterNet 0.5.6 清理背景噪声，将净化短句另存到 `local-voice\data\clean68`，共24句、约120秒；新参数和训练日志分别位于该数据目录及 `local-voice\logs\dafeiyu_clean68`。第8份安静片段的均方根电平在处理前后由约-42dBFS降至-65dBFS，该数字仅反映素材的底噪变化，不代表合成音质评分。

净化版另有本地合成后降噪，最多衰减30dB，处理时间约每6秒音频不到1秒，不调用外部语音接口。新模型和旧模型分开保存，支持恢复旧版配置。

## 服务器连接与备用

配套插件 `astrbot_plugin_fish_hybrid_voice` 对原来的 `bailian_voice` 提供商增加本地优先调用，备用仍直接使用该提供商原有配置，不复制 API Key，不改变聊天权限与语音概率。

用户已明确允许专用账号和密钥用于自动重连。服务器账号为 `fishvoice`，禁用交互终端、任意命令和其他机器人数据访问，只通过专用连接转发语音。私钥仅保存在本地 `local-voice\ssh`，服务器只安装公钥。随机语音请求凭据只在本地文件和服务器插件数据目录保存。语音接口仅监听本机，不开放新的公网端口。

连接在服务器共享数据目录创建 Unix socket，供机器人容器访问。先用两秒健康检查确认本地可用，再发送合成请求；失败后短暂使用云端备用并自动重试。停止本地服务不会停止服务器机器人。

服务器及本机均检查专用语音连接是否失联。服务器对 `fishvoice` 单独设置10秒检查、连续两次无响应后回收旧连接，防止断网留下的旧 socket 挡住恢复。该设置不改变其他账号的连接。

更新前配置备份在服务器 `/opt/dafeiyu/backups/local-voice-20261107`。停用配套插件后会恢复原语音提供商的调用。

## 排查

本地运行状态在 `local-voice\status.json`，连接日志在 `local-voice\logs\connection.log`，模型日志在 `local-voice\logs\service.log`。模型未就绪时仍使用云端声音。模型训练日志在同一个日志目录。

试听生成后保存在 `local-voice\试听`。短素材训练只能作为第一版，音色、语气和发音质量以试听为准，可以继续补充同一位说话人的清晰素材。
