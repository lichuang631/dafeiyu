# 目录与恢复说明

本资料包归档的是步骤、模板与定制代码。已有电脑和服务器的运行目录不会被打包操作修改。

| 目录 | 用途 | 需要另行准备 |
|---|---|---|
| custom-plugins | 两个定制插件与测试 | AstrBot及QQ空间基础插件 |
| local-voice | 本地训练、服务、自动连接 | Python、CUDA环境、模型、ffmpeg、DeepFilterNet |
| 云端部署 | 迁移/启动/安装与诊断脚本 | 服务器、Docker、对应镜像、私密运行数据 |
| persona | 上游大肥鱼人格 | 在AstrBot导入并设为默认 |
| examples | 空配置及填写清单 | 自己的账号和本地密钥 |
| docs | 完整步骤及历史操作说明 | 重新部署时逐项验收 |

`云端部署/install-*.py` 从仓库根目录的 `本机登录信息.json` 读取自己创建的登录信息，管理连接需先建立。安装包输出目录 `downloads` 要自行创建。文件上传需要先在本机完成检查，不应将自己的运行配置提交 Git。

`local-voice/manager.py`、面板连接脚本及若干历史配置脚本保留了示例 `203.0.113.10`。部署时统一填写自己的服务器；主人和机器人示例号码也要替换。不要把任何示例值当成原账号。

恢复顺序：先恢复云端QQ和聊天 → 云端语音与表情 → 空间权限与审核 → 本地模型试听 → 专用语音连接 → 自动回退/恢复验证。QQ扫码登录、Key填写和训练权重准备无法由公开资料包代替。

模型和第三方安装包从其官方项目下载；本仓库不重复分发第三方二进制与用户声纹。上游大肥鱼人格的MIT声明保存在 `licenses`。黑名单插件只记录安装来源和优先级改动，源码仍由其上游提供。
