# 大肥鱼本地声音与云端备用语音

用户已选择本地运行语音模型，本地断开时使用现有龙嫱音色，并指定《标准录音 6.mp3》为训练素材。

后续补充：第8份录音作为同一人的新素材；用户明确指出第7份发错，禁止纳入训练。修复旧版杂音时，保留原权重，对第6、8份进行 DeepFilterNet 全带语音增强，选出24条约120秒短句，在独立 `dafeiyu_clean68` 实验中重训。合成结果再做最多30dB的降噪，保存处理前后试听以供比较，不把听写分数当作音质评价。

## 行为

QQ、对话模型、空间功能继续在现有服务器运行。语音请求优先调用本地 GPT-SoVITS 服务；本地连接失败、超时或音频无效时，同一条回复自动调用现有百炼语音提供商，保持龙嫱音色和语音60%、文字40%的设置。本地恢复后自动恢复优先使用本地，不要求主人手工切换。

## 部署

使用本机 RTX 5060 Laptop 8GB 显卡建立独立 Python 环境，先以小批次完成 GPT-SoVITS v2Pro 系列训练。保留录音原文件，将训练切片、转录、训练参数、权重和试听保存到运行目录，便于重新训练和回退。不会启动本机 QQ 副本。

语音服务仅监听本机回环地址。使用独立 SSH 密钥和受限的服务器连接，把语音接口转发为共享数据目录中的 Unix socket，服务器插件通过该 socket 请求本机，不新增公网端口。本地启动器负责启动服务、恢复连接并记录日志；服务器继续独立运行。本地服务仅处理文本合成，要求请求凭据、长度限制与并发限制。

断网恢复修复：客户端与服务器两端均对专用连接设置10秒保活、连续2次无响应时释放旧会话，避免旧 Unix socket 阻挡重连。服务器设置仅对 `fishvoice` 生效，保留原来的目录隔离和命令限制。管理器每5秒重试并记录连接失败原因。云端在下一次语音请求时尝试本地，失败退避15秒后恢复重试。

## 服务器插件

独立配套插件为指定百炼提供商增加本地优先调用，不修改 AstrBot 核心、不复制现有 API Key。保存原始语音调用用于备用，重载和卸载时恢复。使用连接超时、合成时限、短暂失败退避，防止电脑关机后每条语音长时间等待。

## 验证

验证录音与切片可读、GPU可用、训练确实产出新权重、未见训练句的试听可生成。对自动切换测试本地正常、断开、超时、无效音频、恢复和并发；实际服务器分别验证本地语音及备用语音，只生成音频，不代用户向其他人发送测试消息。更新前备份相关配置和插件，保留原百炼语音配置。

## 完成条件

本地模型可生成新文本语音，云端能取回音频；本地不可用时原音色可正常生成，本地恢复后自动回归。提供易用的启动和停止入口，以及本地声音试听。训练效果由试听体现，不将技术接通当作声音质量保证。
